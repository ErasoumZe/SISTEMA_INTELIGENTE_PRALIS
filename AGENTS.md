# Instrucoes do projeto

- Nao alterar, recriar, ajustar ou gerar migrations sem pedido explicito do usuario.
- Nao rodar builds durante o ciclo de edicao, salvo quando o usuario pedir.
- Rodar testes apenas no final de todas as edicoes, nao a cada alteracao pequena.
- Antes de validar, priorizar checks pontuais e leitura de codigo quando necessario; validacao pesada fica para o fechamento.
